Setup Checklist

  1. Install Python dependencies

    In Terminal, run:
    cd prompt-injection-shield/api && pip3 install -r requirements.txt

  2. Start the detection API

    Run the install script to register the auto-start service:
    bash service/install.sh

  3. Set your API key (optional — enables AI analysis)

    Run: python3 service/set-env-vars.py
    Paste your Anthropic API key when prompted. Get a key at console.anthropic.com

  4. You're done — visit any webpage

    The shield icon will show a green OK badge on safe pages and an amber/red score on pages with detected patterns.
